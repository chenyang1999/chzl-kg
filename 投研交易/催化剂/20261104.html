5.1 资本市场政策与银行间资金：先分清四个钱包

事实更新： 11/3互换便利实际1000亿元、10bp已取央行结果；11/5两笔国库定存各计划1000亿元。11/2再贷款长期化与1%利率的政策脉络继续保留，但本轮不重演“今日新降息”，也未取得新的银行端报价。[N01、N06、H01]

作用路径不是一个加法：

  1. 互换便利：资产互换 → 高流动性资产 → 合规融资 → 实际股票／ETF投资。央行结果解决“操作是否发生、规模和费率”，没有解决最终何时买、买谁。
  2. 回购增持贷款：再贷款成本 → 银行贷款报价／审批 → 企业提款 → 实际回购增持。1%不是全部企业实际融资利率。
  3. 国库现金管理：国库存款向商业银行定存配置 → 银行间流动性和资金成本；要考虑到期和其他公开市场操作，不等于财政多花2000亿元，更不能与SFISF简单相加叫“3000亿元A股净流入”。
  4. 主动ETF：募集 → 成立 → 建仓。旧募集规模既不是当天入市额，也不能和回购、互换投向重叠部分重复计算。
