守正出奇 · 独立逻辑驱动预案

这份预案是什么

这是与原有“盘前预案”并行的一份独立判断，供用户自行对照，不是原版预案增加栏目，也不是把原名单换一种文风重写。

  • 原版继续在：chzl_kg/投研交易/盘前预案/YYYYMMDD.md。
  • 本版独立写入：chzl_kg/投研交易/守正出奇/YYYYMMDD.md。
  • 核心问题：当下市场最值得坚持的逻辑是什么，为什么资金愿意为它买单，谁是最合适的承载者，如何围绕这条逻辑选股和交易。
  • 不预设两份结论应该相同，也不刻意选不同的股票来制造差异；同票也必须由本版独立论证。

思考的重心

先看市场环境、风格和真正的主要矛盾，再解释政策、经济、时局或产业变化如何进入供求、利润、稀缺性和资金偏好，最后选择市场实际认可的核心载体。

“守正”守的是逻辑根基和证据，不是守死股票代码。“出奇”是理解市场为何选择某个载体与预期差，不是每天寻找冷门、补涨或新故事。

不以精确情绪节点、日内最强形态或频繁换股为研究中心。每天核对新事实；逻辑和核心地位没有实质变化时，可以连续跟踪同一方向和同一股票；发生证伪时也不能为维持一致性而硬扛。

逻辑不等于必须有产业业绩：市场确在交易情绪、符号和共同注意力时如实研究，但不把情绪接力伪装成利润兑现。

正文应当讲透的内容

采用连贯文字，必要时辅以简表，不另造固定评分器或每日凑数目标。以下是要回答的问题，不是要求每天机械填满的字段：

  1. 这一段行情在交易什么。 市场环境、资金审美、主要矛盾；事实与推断分别说清。
  2. 最硬的逻辑是什么。 变化的源头、传导路径、持续性、尚未被价格反映的部分，以及最重要的反证。宏观叙事不能直接跳到个股。
  3. 为什么选这些核心。 逐票说明受益与概念真伪、辨识度、市场地位、筹码约束及相对其他同方向对象的优势。先有逻辑和证据，再有股票，不给既定名单补故事。
  4. 如何围绕逻辑交易。 什么条件下值得介入，什么情况下等待，为什么可以继续持有，什么变化需要减仓或退出；区分方向看好、目前适合买入和已有持仓维护。已有可核价位可作条件参考，缺价格事实不编数，也不让价位表压倒逻辑判断。
  5. 今天与此前相比。 延续、强化、削弱或推翻了什么，新证据是什么；没有变化可以明确不变。首份报告写首次建立，历史不足写未核，不伪造连续跟踪。
  6. 什么会推翻判断。 分清事实证伪、预期兑现、市场不认可与正常波动；没有可参与机会可以等待，不因每天要出报告而交易。

怎样保持两份对照有意义

  • 独立会话分析，优先复用同批、同一事实窗口的真实研究材料，不重抓一遍全市场。
  • 本版先完成自己的逻辑与选股判断，不先读取原版最终名单再模仿或刻意反选。
  • 两版信息截止不同时如实注明，不把信息优势冒称思维方式优势。
  • 后续报告读取本目录前一份真实报告来维护自己的逻辑，不将原版预案当成本版的昨日观点。
  • 对比由用户进行；不建立自动胜负评分、强制换股率或额外回测工程。

与原交易系统的边界

本版是人读的选股与交易研究，不生成或覆盖watchlist_plan.json，不写runtime，不进入自动执行，也不修改原版名单、价位、仓位与交易规则。它可以给出有依据的条件交易判断，但不是另开一个自动交易通道。

流通市值硬线、T+1、真实风险和既有退出纪律不因“逻辑更硬”被豁免；不能亏损后临时把短线改称长线。不开仓不停止研究。
