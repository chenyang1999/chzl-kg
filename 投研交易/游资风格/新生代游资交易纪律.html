新生代游资交易纪律

从《解密新生代游资·交割单》五人心法抽出的可执行规则。原文见同目录 新生代游资核心观点整理.md。

用法：先守铁律，再选一套主模板。铁律与主模板冲突时，听铁律。不要把五人打法焊成一套超级策略。

仓位默认按学习样本（涅槃碎仓 + 科比分仓）。陈小群式重仓总龙、北哥小资金满仓，只在主模板里显式打开。

0. 每天先问四件事

盘前写在纸上，写不出来就空仓。

  1. 市场在为什么付钱？ 风格 / 主线 / 赚钱效应 / 阶段之王，名字不同，问的是同一件事。
  2. 现在处在哪一段？ 低位试错 / 主升 / 高位震荡 / 主跌。段位错了，后面全错。
  3. 谁有地位？ 总龙、补涨龙、低位前排。中位和杂毛直接划掉。
  4. 今天计划做什么、不做什么？ 计划外不出手。

1. 十条铁律

违反任一条，当天剩余额度清零，记过错。

#铁律执行口径
1先认市场，再认个股没有主线 / 风格 / 赚钱效应，不准开新仓。不准先爱上某只票再找理由。
2只做龙头或低位，躲开中位和杂毛自选只放龙头；非龙头进备选。有总龙不做分龙，有连板不做反包龙，有主升不做反抽，有主线不做支线，有明牌不挖暗线，有市场选出的龙不做自己选的龙。
3周期不对就减维确认退潮、无持续性主流、亏钱扩散 → 空仓或极小试仓。不准靠「我比市场聪明」逆势。
4模式外的钱永远不赚自己做不顺的板块、图形、位置，直接拉黑。错过鸡头宁可等凤尾。
5进出理由必须一致进场逻辑被证伪就出场。逻辑还在、分时坏了可以减；逻辑死了必须切。
6盈亏比优先于胜率强于预期加一点仓，弱于预期减仓。不准用加仓摊平「我不甘心」。大肉来自少数核心单，多数日子是试错。
7合力来自全市场，不是游资抱团没跟风赚钱效应、没封单承接，不准当「有人护盘」硬做。大单砸而封单增，才叫合力还在。
8计划外不出手杜绝临时起意。盘中新票必须能回答：它是今日核心 / 主线补涨 / 计划内试错 中的哪一种。都不是，不买。
9错了快切，不讲故事超短不达预期隔日走人。看错了跌停也要切，切不出次日切。不准套三四天等叙事兑现。
10系统大于新技巧当天不研究新打法。复盘只升级树干上的树枝，融不进系统的舍弃。

原话锚点：北哥「永远不要妄想去挣你的模式外的钱」；陈小群「市场没有错，错的是自己的预判」；科比「要么做高，要么做低」；涅槃「跟着情绪走，千万不要自以为是」；光神「杜绝临时起意，只计划操作」。

2. 开仓资格（必须同时满足）

缺一条不准买。

  • 今日主线或风格已经写在计划里，不是盘中才「发现」。
  • 标的是：当日人气总龙 / 主线补涨龙 / 低位前排（首板或二板） 三者之一。
  • 个股有市场地位：能带板块、能带跟风赚钱效应，或明确是低位复制最强效应。
  • 不在下降趋势，不做近期涨幅过大的防御板冒充进攻。
  • 买点属于计划内手法（见第 5 节），不是看着眼熟。
  • 仓位不超过当日额度与单票上限（见第 4 节）。
  • 若处于亏钱周期：只允许「舌头碰热水」的试仓，不准当主仓。

龙头认定（过 3 条才叫龙，数板不算）：

  1. 高度或阶段涨幅有辨识度，市场公认，不是你主观命名。
  2. 逻辑硬，最好能映射业绩或国策。
  3. 能带动板块，光杆司令走不远。
  4. 容量和换手够，能让人上下车。缩量一字连板多是情绪股，不是龙头，少做。

合力认定（至少看到一件）：

  • 龙头上板后，板块出现跟风涨停或明显赚钱效应。
  • 大单砸、封单反而增大。
  • 该弱不弱视为强；该强不强视为弱——后者直接降级或放弃。

3. 禁止清单

这些不是「谨慎」，是禁止。

  1. 中位股、杂毛、没地位的弱转强。
  2. 已有既定主流时，去看非主流（光神：等于犯罪）。
  3. 最强板块的对立面。
  4. 非主流冷门当低风险重仓。
  5. 情绪差时抓小转折点逆情绪。
  6. 确认退潮后还买；买了还不立刻止损。
  7. 博弈穿越高潮、末期机会当主仓。
  8. 下降趋势板、无板块效应的秒拉板。
  9. 14:00–14:30 后的投机点火板（除非是高位久横的换手板，且主模板允许）。
  10. 计划外扫板、广撒网蒙一个。
  11. 手风不顺还隔夜赌反转。
  12. 用 T 或补仓掩盖看错。
  13. 梭哈学习期账户（退学样本不作学习模板）。
  14. 把「纯图形 / 庄票」和「总龙锁仓」同一天混用。

4. 仓位纪律（默认学习模板）

目标：大涨小回，活得久。复利来自分仓，不来自神单。

项目默认规则
单票1–2 成。到 1/3 算重仓，必须满足「核心 + 主升 + 计划内」。
单日总仓试错期 ≤ 3 成；主升期可到 6–8 成，仍分在 2–4 只核心上。
满仓仅当三点共振：指数单边向上 + 板块为当日核心 + 个股是板块人气容量核心。否则不准满。
弱于预期立刻降一档仓位，不是「再看看」。
强于预期最多加 20% 相对仓，仍受单票上限约束。
底线设资金安全垫。靠近底线时只做小仓确定性，先赚回来再恢复。
创业板 / 20cm / 下午板默认再腰斩一档（北哥：下午、创业板用 1/8 思维）。
排板 vs 扫板扫板少而精；排板可多分，避免买不到导致该满不满。

加仓只允许： 计划内核心票，分时未坏，合力还在，且是逐步加，不是一把补。

减仓立刻发生： 分时出现问题；该加速不加速；该回封不回封；总龙首阴被按。

5. 买入纪律

默认手法顺序：打板 / 半路 > 低吸。低吸不是禁区，但是特权：只有主模板允许、且标的是看好的合力票时才能用。

5.1 打板

先定氛围：做中高位进攻，还是低位防御。不要混打。

板型允许不允许
换手板5–8 个点横够久（半小时级）再一笔上板，可扫横了两分钟就当换手
回封板炸后回封，空头卖完多次打开、尾盘才封
秒拉板必须有板块效应（前排已红），优先排不优先冲下降趋势、涨幅过大、板块全绿只有两红
中军板下午若打，优先行业一提就想到的名企杂毛冒充中军
尾盘板尽量不打；若打，只打高位久横换手板14:30 后点火板
反包总龙首阴反包可当市场开关；大资金舒适区偏反包二板衰退期反包当主仓（次日开盘就是卖点）

5.2 半路

允许：竞价或盘中超预期走强、核心票、量能能解释。
少做原因：量不好确定。看不准就改排板，不猜半路。

5.3 低吸

仅当：已经认定合力票 / 总龙 / 主线首次调整后的回流。
禁止：用低吸给杂毛、给退潮、给「套了当投资」。
翘板：非趋势、非硬逻辑票，次日不涨停就清空。

5.4 核按钮

默认当风险，不当策略。
高位核了对低位影响不大，可转做低位补涨，不准去接核按钮本身。
反核只留给「总龙锁仓」主模板，且必须是市场总龙、合力仍在。学习期关闭。

6. 持有、换龙、补涨

持有

  • 逻辑在、合力在、分时未坏：拿。不爱做无效 T。
  • 超短隔日模式：次日溢价兑现就换股，不编「变趋势了」。
  • 格局模式：事先写明「拿两板第三天走」或「拿到巅峰」，到期执行，不准盘中改剧本。

换龙

  • 总龙熄火、题材未退潮、新龙坚挺 → 立刻换新龙，过气龙头不如狗。
  • 龙头不停地换、没有一只能打高度 → 合力差，降仓，不要追每一只新高标。
  • 迷茫期后来者居上极难，不要幻想补涨龙一夜变总龙。

补涨

  • 只补主流，且龙头没走完。
  • 最佳窗口：龙头急拉后的前一两次分歧转强。越往后越容易补跌。
  • 第一次后排涨停潮看不清谁是补涨龙 → 等谁能晋级二板。
  • 弱市无主线时，补涨 = 复制最强效应到低位首板 / 二板，不是去中位捡。

7. 卖出与止损

止损快于叙事。市场没错，错的是预判。

情形动作
进场逻辑被证伪立刻切，跌停也切，切不出次日切
超短不达预期隔日走人
确认退潮不再买；手里的果断止损
总龙首阴被按 / 背合减到风控仓或空，等待大调整，不准抄在半山腰
手风不顺尽量不隔夜；次日赚钱就走，不管卖飞。先回血，再谈格局
分时出现问题先减，再决定是否还做
一致加速、人人都觉得稳是卖出区，不是加仓区（买入分歧，卖出一致）

不准：等财报、等故事、等「它应该反包」。分析越细越容易不止损。

8. 情绪周期：强制切换表

每天给市场贴一种标签。标签决定仓位和手法，不准「我觉得还能搏」。

阶段盘面特征允许禁止
低位试错老题材冰点、新题材轮动、无主线打首板；低位补涨；切新题材；轻仓试错猛干高位龙；重仓
主升龙头打出高度，主线确认，板块普涨干龙头（打板 / 竞价 / 半路）；同题材连板补涨或低位潜伏；故事还能讲就敢在分歧买还在玩支线、暗线、自己选的龙
高位震荡亏钱效应出现，龙头断板，低位补涨落袋、轻仓；龙头未死可挖主线低位博弈穿越
主跌 / 退潮龙头人气股大跌甚至跌停，亏钱扩散空仓为主；连冰后尾盘试错；切全新题材一日游参与小反抽当主升；情绪票逆势
补跌周期连板各种大面且继续杀，强转弱就大跌尽量不碰情绪票，除非与指数共振大阳当超跌反弹满仓

总龙开关（即使不做总龙，也拿来定温度）：

  • 总龙首阴后反包 → 行情还可能继续。
  • 总龙首阴后被按 → 准备调整。
  • 总龙第一次被关 → 可看板块内中位加速 / 补涨（仍躲开没地位的）。
  • 总龙第二次被关 → 小心高位板做多情绪。
  • 无持续性主流 + 指数下跌或盘整 → 空仓。多数人亏在小反抽，不在普跌。

指数 × 情绪： 情绪很好但指数阴跌，情绪一弱可能变大跌。两者同向才能上仓位。

9. 每日流程

盘前（计划单，必须写）

  1. 昨日涨停溢价、炸板、连板高度、亏钱效应 → 给情绪贴标签。
  2. 写出今日主线候选、总龙、补涨观察、低位前排。非龙头放次要栏，早盘前 30 分钟不看。
  3. 写出今日不做的方向（对立面、退潮、模式外）。
  4. 给每只计划票：买点类型、仓位、失败标准、隔日还是格局。
  5. 标定：今天是不是空仓日。是，就只许试仓额度。

盘中

  • 前 30 分钟只盯龙头。
  • 只执行计划单。新票要能归入「今日核心 / 主线补涨 / 计划试错」。
  • 强于预期才加档，弱于预期立刻减。
  • 不处理上一笔的情绪：无论好坏，下一笔当新题。

盘后（错题集，必须写）

按涅槃口径，走马观花等于没复盘：

  1. 今天计划内机会做了没有，仓位对不对。
  2. 昨日涨停：谁溢价高 / 低，卖点怎么处理。
  3. 炸板为什么炸，以后怎么避开。
  4. 哪一笔是模式外、临时起意、叙事不止损。
  5. 只把能融入树干的记成树枝。矛盾的要写清「哪里错了」，不要标成「模式内亏损」了事。

10. 手风、空仓、体能

  • 不会空仓，永远做不大。 亏钱周期下雨不出门。
  • 空仓日可用极小仓试水温，防思维钝化，不准把试仓做成主仓。
  • 手风不顺：不隔夜；次日赚钱就走。回血后再等舒服买点，否则回撤变腰斩。
  • 弱修复、僵持：看戏。
  • 市场低迷忍住；市场火爆把自己当傻子随大流。趋势没改，不猜顶底。
  • 一天只做计划内的正确重复。交易的本质是复杂变简单、正确操作重复化。

11. 主模板（只选一套叠加在铁律上）

选完写在计划页第一行，两周内不准换。换模板必须先空仓复盘，不能盘中切换人格。

A. 首板隔日（北京炒家）

  • 主做低位首板，吃次日溢价，第二天换股。
  • 滤网：风格 → 赚钱板块 → 有效共振（时刻强于指数）→ 辨识度。
  • 不锁仓总龙，不靠维护吃饭。弱市空，情绪牛切换，成熟牛咬行业核心。
  • 小资金可瞄准一只龙头；大资金切开。牛市哲学是仓位利用率，但不得突破铁律 3。

B. 总龙锁仓（陈小群）

  • 只做人气总龙，或打造总龙。看好则低吸 / 半路 / 打板 / 维护都可以。
  • 用总龙首阴反包 / 被按当市场开关。熄火换新龙要果断。
  • 不爱做 T，看准拿到巅峰。翘板次日不涨停清空。
  • 反核、核按钮买点仅此模板，学习期关闭。
  • 分仓控回撤，但对认定的总龙可逐步加重。

C. 三格轮换（92科比）

  • 世界观只有三格：龙头 / 补涨 / 切换。按情绪四段填内容。
  • 反包二板是大资金舒适区。半路少做。反对梭哈。
  • 时机比题材内容重要。高低切发生在龙头见顶杀高位时。
  • 超短就是隔日，不达预期走人。

D. 情绪树干打板（涅槃重升）

  • 先看六情绪里哪根变量最先引领，再决定做低位前排还是给龙头仓。
  • 确定性两件事：打板 + 做核心。半路和打板多，很少低吸。
  • 无主流 + 指数弱 = 空仓。下降趋势不做。
  • 单票 1–2 成，放弃小机会。

E. 高位分歧接力（一瞬流光）

  • 只做阶段之王。买入分歧，卖出一致。不做低吸。
  • 人气龙分歧进，常锁两板、第三天退。
  • 满仓必须三点共振。计划外不出手。空仓是技能。
  • 型必须符合神：地位不对，图形无效。

12. 一页纸口令（贴桌上）

  1. 没主线，空。
  2. 不是龙、不是低位前排，空。
  3. 计划外，空。
  4. 退潮 / 下雨 / 无主流，空。
  5. 弱于预期减，强于预期才加一档。
  6. 逻辑死了就切，跌停也切。
  7. 过气龙换新龙，中位杂毛不碰。
  8. 买入分歧，卖出一致。
  9. 手风不顺次日赚钱走。
  10. 今天只重复对的动作，不研究新打法。

附：和心法稿的关系

  • 本页是纪律：能勾选、能违反、能记过错。
  • 心法稿是原文和对照：盘中不要翻 55 条，盘后对照原话升级树干。
  • 城邦股份那种分叉已经说明：同一天，北哥打首板次日走、群神做后排补涨，是两套系统。纪律允许你只跑其中一套。
