一句话结论

分歧期轻装上阵——仓位上限53%，执行池仅3只（PTFE新分支为主+算力龙一辅+农业观察），R6砍了R2一半候选（11条strong_suggest全部采纳），今日策略是”开盘30分钟看哪条主线超预期就打哪条，另一条放弃”。

市场全景：82家涨停背后的47.6%炸板率

周五的盘面很有意思。涨停82家，数量不少，但炸板率冲到了47.6%——什么概念？两家打板就有一家炸。这不是健康的情绪扩散，这是典型的分歧加剧期。

连板梯队看着完整：7板、5板、4板、3板、2板逐级分布，但仔细一看——7板的深中华A孤零零一只，5板也只有一只，高位梯队薄得像纸。一旦深中华A周一断板，高位连板的标杆效应就塌了，下面4板3板的票能不能扛住？不好说。

大小盘分化走到了极端：中证1000一个月涨了6.1%，科创50跌了12.7%。这不是板块轮动，这是风格撕裂。资金一窝蜂扎进小盘情绪股，大盘股和科技成长被持续抽血。

北向资金倒是挺稳的，连续5天净流入，每天25-29亿的节奏。但钱都去哪儿了？看主力资金流入榜就知道——前三名全是AI方向：AI应用+32.94亿、AIGC+26.18亿、AI智能体+25.88亿。可AI的龙头股呢？中际旭创跌0.9%，亨通光电跌3.65%，通鼎互联跌5.96%。

资金在AI内部做高低切换，从老龙头往新分支搬。 PTFE材料就是那个新方向。

两条主线，一个真一个悬

粮食安全：热榜新科状元，但底子薄

R2给粮食安全打了86分，排第一。R3也给了86.5分的共振分，概念榜从第9直接飙到第1，势头很猛。

但往下挖就虚了。

消息面：R4的8个催化事件里，没有一条跟农业沾边。所谓的”摩根大通粮食危机预警”是KOL群里传的，不是官方发布的硬新闻。涨价逻辑有多大实锤？不好说。

资金面：农业种植主力净流入8.47亿，听起来不少，但排名是第27名。第1名是AI应用的32.94亿，差了快4倍。5日资金追踪池里根本没农业什么事。

基本面：R5扫了5只农业股，3只亏损——金健米业PE-187.5、新赛股份PE-35.2、敦煌种业PE-48.7。龙一万向德农倒是盈利，但PE 95.3倍，流通市值才15.2亿（S1庄股风险）。

龙虎榜：金健米业周五换手率45%，龙虎榜净卖出1.8亿，还疑似对倒。这不是建仓，这是出货。

所以这条线的定位很清楚：纯情绪驱动的early阶段题材，有高度（万向德农4连板）但没厚度（资金+基本面都弱）。能走多远完全看情绪能不能持续发酵，一日游的风险不小。

D1的处理：不进执行池，只观察。 万向德农如果周一超预期5连板，可以极小仓位（3%以内）追一下，但那是刀尖舔血，不是主线配置。

AI算力/光通信：四源全中，但late了

AI算力的情况刚好反过来：R2/R3/R4/R7四源全中，资金面最强（主力流入前三全包），但阶段是late——高位分歧、老龙头出货、新分支接力。

CPO概念榜从第1跌到第6，老龙头们普遍回调3-6%。R3直接给了distribution_alert，R6更是说”高位出货确认”。

但AI这条线没死，它在内部切换。PTFE材料是新冒出来的分支——英伟达十几亿订单，switch/midplane/LPU板子陆续换材料，这是有增量逻辑的。沃特股份2连板（还曾经20cm过）、昊华科技2连板，都是这个逻辑。

问题是，昊华科技也被R6盯上了——连续3日涨幅偏离值20%上榜，净卖出3.2亿，机构净卖5.19亿，还疑似对倒。这票是拉高出货的典型。

那PTFE分支里还剩谁干净点？沃特股份。PE 78.3倍不便宜，但55亿流通市值，弹性够，2连板的走势也干净（没被机构砸盘的痕迹）。加上星网锐捷作为算力线龙一（2连板，278亿中军），AI线就这两只能进执行池。

仓位为什么是53%

R1给的建议是58%，主线扩散型，合理。但R6有一条strong_suggest明确说”情绪52.5分+47.6%炸板率=分歧剧烈期，建议仓位上限从58%下调至45%”。

我没有完全采纳45%（太保守了，82家涨停摆在那里），也没全信58%（47.6%炸板率不是闹着玩的），取了个中间值53%。

推导链是这样的：

R1主线扩散型 → raw_cap = 0.58
R7北向连续5日净流入 → +0.03 → r7_adj = 0.61
情绪周期：乐观分歧期（58分，20-60区间）→ 不override → 0.58
双主线 → multiplier = 1.0
R6分歧风险调整 → -0.05
最终 = min(0.58, 0.61, 0.58) × 1.0 - 0.05 = 0.53

53%的仓位，执行池3只票加起来最大仓位才25%，剩28%是留给加仓和T+1的。分歧期手里留着子弹不丢人。

执行池三只票详解

1. 沃特股份（002886.SZ）— 核心仓位 12%

买入理由：

  • PTFE新材料是AI算力最新分支，英伟达十几亿订单实锤，逻辑增量明确
  • 2连板（前面还吃过20cm的），弹性够大，55亿流通市值适合做弹性配置
  • R5 alpha=A级，综合得分83分，和星网锐捷并列第一
  • 不是老龙头，没有前期套牢盘压力

为什么敢给12%：
这是今日执行池里最”干净”的一只票——不在R6 strong_suggest名单里，没有机构出货信号，没有对倒嫌疑，估值虽然78倍不算便宜但在AI新分支里可以接受。作为PTFE分支的弹性龙头，12%的仓位是合理的。

风险点：

  • PTFE逻辑传播还不广，可能只有少数资金在做，持续性存疑
  • 55亿市值不大，情绪退潮时跌起来也快
  • 2连板后有正常回踩需求，追高容易被套

止损条件：跌破19.8元（MA10下方3%），全清。

可验证假设：PTFE材料逻辑在周一获得更多资金认可，沃特股份冲击3连板。如果成立，说明新分支有效，可以加仓到15%。如果周一就冲高回落，说明逻辑传播失败，减半。

2. 星网锐捷（002396.SZ）— 辅助仓位 10%

买入理由：

  • AI算力线龙一，2连板，首封时间09:36（够早，有带动性）
  • 278亿流通市值，算力中军，机构+游资合力
  • R5 alpha=A级，83分
  • 7次开板说明分歧大，但最后还是封住了，说明承接力还行

为什么只有10%：
late阶段的龙一，7次开板的分歧不是好事。龙虎榜机构净卖2494万，虽然金额不大但方向是卖的。CPO整体有distribution_alert，星网锐捷作为算力中军也受板块情绪影响。给10%不轻不重，进可攻退可守。

风险点：

  • late阶段龙头，随时可能见顶
  • 7次开板显示抛压重，周一低开压力大
  • 老龙头中际旭创还在下跌趋势中，可能拖累板块

止损条件：跌破30.5元（MA10附近），全清。

可验证假设：周一算力线修复，星网锐捷缩量3板确认分歧转一致。如果成立，加到15%。如果低开低走破MA10，说明late阶段确认结束，立刻走。

3. 万向德农（600371.SH）— 观察待确认 3%

为什么放在执行池边缘：
严格来说这票应该在观察池，但它是农业线的空间板（4连板），如果周一超预期5连板，说明农业线真的能走出来，那时再追就晚了。所以给3%的极小仓位，相当于买个期权——赌对了赚点，赌错了也不伤筋动骨。

为什么不能多买：

  • 流通市值15.2亿，触发S1硬约束（<20亿直接剔除），庄股风险极高
  • PE 95.3倍，种子行业平均才30-40倍，溢价超100%
  • 4连板高度，追高就是接最后一棒的风险
  • R6两条strong_suggest点名，一条是估值风险，一条是基本面红旗

止损条件：跌破9.2元（MA5附近），全清。小市值票不扛，错了就走。

观察池15只：覆盖三条线+防御+排除

观察池的结构是有意设计的，不是随便凑数：

农业线候补（4只）：新赛股份、敦煌种业、金健米业、新农股份。前两只是看看农业线能不能扩散出第二波，后两只基本就是反指——它们要是还在拉高出货，说明农业线还在情绪亢奋期；它们要是崩了，农业线也就到头了。

AI算力线候补（3只）：昊华科技（出货观察）、中际旭创（老龙头止跌观察）、源杰科技（排除跟踪）。中际旭创是关键——如果这票能止跌企稳，说明AI线的调整告一段落，那时可以考虑把仓位加回来。如果还在创新低，AI线就别碰老的了。

次线主题（4只）：奥比中光（具身智能机器视觉）、豪恩汽电（机器人弹性）、佰维存储（存储HBM）、安恒信息（网络安全）。都是R4有催化但R2没列主线的方向。万一哪条周一突然爆了，观察池里有票可以快速跟进。

防御/其他（4只）：立讯精密（苹果链）、万华化学（化工避险）、山东黄金（黄金避险）、哈药股份（情绪反指）。

哈药股份放进去纯粹是当情绪温度计——热股榜第1、连续霸榜、但创新药板块在出货。这种票如果还能继续涨，说明市场情绪很热，什么垃圾都能飞；如果它崩了，说明情绪退潮了，高位票都要小心。

R6反证：11条strong_suggest全采纳

今天R6的工作量很大，一共出了16条反证：0条hard_reject + 11条strong_suggest + 5条soft_suggest。

为什么没有hard_reject？因为模式六（霸榜出货硬约束）的第二条——“主力5日净流出”——R5筹码数据降级了，确认不了。按规则，缺一条就不能算hard_reject，只能降级成strong_suggest。

但这11条strong_suggest，D1一条都没打回，全吃了。

吃的逻辑是：

  • 农业线的60%亏损股 + 小市值庄股风险 → 全部剔除执行池，只留万向德农观察
  • AI线的高位出货风险 → 老龙头全部移出执行池，只留新分支
  • 机构出货+疑似对倒的票（金健米业、昊华科技、新农股份）→ 全部剔除
  • 分歧期仓位下调 → 从58%降到53%

这就是反证Agent的价值——它不是来否决一切的，它是逼着你在情绪热的时候冷下来，把那些”看起来很美但底子很脏”的票挑出来。

今日操盘纪律

  1. 开盘30分钟不瞎动：先看两条主线谁强谁弱。粮食线如果高开低走，直接放弃；AI线如果高开高走，可以加仓沃特股份。
  2. PTFE是今日核心：这条线的持续性决定了AI仓位能不能加。沃特股份是风向标。
  3. 万向德农看戏为主：4板到5板这一步，成了就是情绪龙头，败了就是天地板。3%仓位试试水，错了马上走。
  4. 炸板率是关键指标：如果周一上午炸板率就超过40%，说明分歧继续扩大，什么票都别追了，手里有的找机会减。
  5. 北向好歹是支撑：连续5天净流入说明外资没撤，大盘系统性风险不大。但外资买的是大盘股，小票情绪退潮的时候，外资救不了你。
