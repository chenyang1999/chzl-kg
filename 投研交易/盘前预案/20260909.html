一句话结论

高位震荡的第二天。涨停还有七十三家、跌停零家，但炸板率依旧卡在三成四的高位，连板高度从六板降到四板后没有恢复，前日涨停溢价从四六个点一路回落到两个九——赚钱效应还在，但已经从普涨切成分化，而且这个”分化”延续到了第二天。今天能做的，还是只有两条主线里”资金干净、估值不贵、买点成立”的票，仓位上限五成五，实际首日只建仓一成三左右，剩下的空间全部留给确认。

市场在为什么付钱

先说结论：今天市场在付钱的方向，和昨天完全同构——“涨价”和”政策”，不是”科技”。

农业这条线已经发酵到第四天了，从九四的猪肉，到九七的粮食，到九八七个概念霸占热榜，今天（九零九）是第九个交易周里的扩散中后期。催化依旧硬：超强厄尔尼诺被世界粮食计划署确认会加剧全球粮食不安全，六部门发文支持涉农企业上市，农业农村现代化”十五五”规划落地，泰国糖减产百分之十七。R3 把农业排在共振第一，R4 给到 high 级催化，R2 给到八十五分——这是全市场最拥挤的主线，没有之一。

但拥挤本身就是风险。龙一亚盛集团四连板一字，换手不到百分之一，PE 一百九十（一年百分位满格），主力五日净流出六点六七亿，机构专用席位在净卖，盘后还发了风险提示公告。龙二敦煌种业三板换手充分，PB 六点五，主力五日也在净流出。中粮糖业作为容量中军，首板当天主力净流出九点二五亿——这是教科书级的涨停板出货嫌疑。R6 的反证结论非常直白：农业的”板块资金看着在流入”（磷化工、化工原料单日爆量），但真正涨停的龙头自己全在被主力出货，资金确认是”单日翻红”不是”持续净入”，这个假象今天已经是第二天了。而昨天 R6 的高估值题材龙头规避逻辑四比四兑现（新炬网络、易点天下、恒宝、蓝色光标全跌），今天同构的亚盛、敦煌、中粮、苏垦，估值极端性一点不弱。

另一条主线是资源涨价链：LME 铜今天创出历史新高一万四千六百一十七美元，美国二零二七年精炼铜关税百分之十五的预期引发全球抢铜潮，布伦特原油冲到九十九美元六周新高。黄金概念、稀缺资源、小金属包揽主力净流入前三。但这条线的毛病也延续到了第二天：资金和涨停脱节——紫金、江铜都是趋势票，当天没涨停，A 股黄金股也没一个涨停；而且五日累计资金全部还是净流出（黄金负二十九点七亿、稀缺资源负七十一点一亿、小金属负九十六点七亿），0908 的单日暴动只是五天里唯一或唯二的正日。它是”趋势资金主线”，不是”涨停主线”，段位在启动期，持续性到今天还没验证。

科技硬件（光模块、CPO、液冷、存储）是两周前的王者，现在确认退潮第二天：热榜全线跌出前十且转负，CPO 从第一滑到第五，液冷、存储、PCB 全线掉队；华为概念流出一百一十亿、人工智能流出九十亿、液冷流出八十四亿。而 R4 的四件 high 催化（GPT-6、存储短缺实锤、铜价新高、6G 商用）里，前三件科技件全部落在资金流出最狠的板块上，外盘存储链也回落了（美光负一点六、英伟达负二点零）——消息最强日等于盘面资金最不认可日，这个背离今天已经是第二天。教科书式的四重背离，只观察，不追，一条腿都不伸。

四象限叉乘：每个候选都过一遍筛子

我按情绪、资金、消息、估值四个象限，把 R2 的十二条候选全部过了一遍：

情绪面，高位震荡第二天，炸板率三成四逼近三成五的硬约束线，连板高度降级后没恢复，昨日资金前十、成交前十这些最活跃资金指标当日全线转负——结论是候选数砍半，禁竞价追高一致，盘中炸板率再破三十五就再砍半、仓位再降。

资金面，双主线全是”单日爆量”第二天：黄金、稀缺、小金属、化工原料、磷化工的五日累计全部净流出，只有紫金一家五日净流入六个多亿（全资源线唯一资金健康）；农业龙头自身筹码背离（亚盛主力五日负六点六七亿加机构净卖，中粮涨停日主力负九点二五亿）；北向倒是稳，连着五天温和流入二十多亿，但方向是大权重和周期，和游资妖股结构完全不同。结论是禁重仓，只做资金相对干净的中军。

消息面，最硬的催化在农业和资源，但都带着”资金持续性弱”的裂缝；科技四件 high 与资金、热榜、外盘全面背离；唯一宏观逆风是美联储九月加息概率升到百分之五十九点四、三年期美债收益率创两年新高——这是压在农业高估值妖股头顶的一把刀。昨天平陆运河中军北部湾港当天跌八个点证伪”隔日映射”，今天所有事件驱动都必须以竞价承接为前提。

估值面，农业龙一极端高估（亚盛 PE190.9、中粮 PE34.8 在百分之九十九点六分位、苏垦百分之百分位），资源中军干净（紫金 PE13.3、江铜 PE14.5 无红旗），候补一堆财务红旗（金正大亏损加高 PB、中曼大宗折价分销）。结论是”贵的不能碰、便宜的没涨停”——可执行空间只在资源趋势中军的低吸，农业只留确认型窗口。

四象限叉乘的总结一句话：今天没有一条线是四象限全绿的，农业线四分之四象限危险（只做确认型），资源线四分之三象限中性偏正（可低吸禁重仓），科技链消息强但资金情绪全面背离（只观察）。R6 今天零 hard_reject，红线三没触发，但十条 strong_suggest 我全部采纳，一条都没覆盖。

今天的执行池：两只，都是资源趋势中军

仓位上限五成五，和 R6 建议的总仓上限完全一致；实际首日只建仓一成三，留加仓空间。

第一只是紫金矿业，资源线龙一，也是全资源线资金最干净的票：当日主力净流入十五亿、五日净流入六点六亿，PE 十三点三、ROE 二十四点五，四十四篇研报覆盖，无任何财务红旗。买点是趋势回踩低吸：回踩 33.2 到 34.0（日线 MA20 和六十分钟上沿）缩量企稳分批买，高开超过两个点放弃；止损设在 31.3（买入价负七个点），跌破 MA60（30.76）趋势走坏清仓，止盈 37.5。首仓百分之八——因为 R6 反复强调资金是单日爆量没验证，五日资金序列连续两天翻红才允许加仓到上限百分之十五，如果明天黄金铜股还是不涨停扩散，加仓窗口直接关闭。

第二只是江西铜业，资源线龙二，铜冶炼弹性，PE 十四点五、PB 一点九二，无红旗。买点是回踩 46.6 到 48.5（MA20 附近）承接，前高 49.85 放量突破才加仓；止损 44.5（负六点五），止盈 52.5。首仓百分之五，轻仓联动，因为五日主力还在小幅净流出，且前高有套牢抛压。

两只都是趋势低吸票，不是打板标的，符合”高位震荡只做龙头分歧低吸或低位补涨”的阶段纪律；也都按波段锁仓档（wave_main）处理——资源线还在启动期一浪，不做 T，五日资金转正后按二浪加仓到百分之十八到二十五。

观察池：二十三只，重点讲农业的”等什么”

农业龙头今天都不进执行池，但都留在最高观察级，因为”等确认”和”放弃”是两回事——错题本 0907_001 教过我：估值反证不该一票否决短线龙头，要用仓位和闸门控制，而不是直接踢掉。

亚盛集团等什么：等放量分歧回封。四板一字今天没买点（九点二十五分就封死，换手不到百分之一），只能等它断板或者打开，出现换手板弱转强的确认型机会才考虑；高开超过五个点直接放弃；它一旦断板，就是农业线退潮的观察锚，所有农业票即时降仓。

敦煌种业等什么：等亚盛断板或分歧时它弱转强，这是接力窗口票，独立低吸不设，高开超五个点放弃。

中粮糖业等什么：等资金承接，主力从净流出转净流入才谈配置，涨停板出货嫌疑没解除前不碰。

金正大、苏垦农发是被 R6 财务红旗直接拦下的，只观察化肥分支联动和补涨跟风，不设买点。

资源线观察池里：北方铜业（铜矿弹性首板，涨停后分歧低吸）、中金黄金（黄金股没涨停，若启动才跟进）、招商南油（油运中军，突破 4.7 前高才打开空间）、中国石油（油权重），以及被 R6 拦下的中曼石油（大宗折价分销，只盯油价持续性）和华锦股份（尾盘弱封，不追）。

科技链全部降为纯观察：中际旭创、金山办公、佰维存储——R6 明确”严禁当执行候选”，等资金转向；CIOE 光博会九月九到十一号开幕，注意利好兑现。

其他值得留意的：CIPS 人民币跨境支付（四方精创、中油资本，新闻联播级催化但容量小易一日游，竞价承接为前提）；6G（武汉凡谷，政策强但资金弱，隔日映射事件）；创新药（千金药业，颜晓滨背书热榜上行但涨停分散）；代糖新晋热榜第一（华宝股份作为 watch 升级路径——若明天再霸榜就是单日登顶兑现剧本，农业执行票即时降仓）；龙版传媒作为情绪温度计锚（七板炸板未回封，ts_code 已按错题本 0908_001 双校验为 605577）。

反证采纳与不交易条件

R6 今天零 hard_reject（霸榜出货双条件没有标的命中，红线三未触发），但有十条 strong_suggest，我全部采纳，没有覆盖任何一条：资源线禁重仓、农业 proxy 资金假象、科技四件套严禁当执行候选、高位震荡候选压缩、亚盛一字无买点、昨日高估值反证四比四兑现、单日爆量警示延续第二天、金正大财务红旗、中曼大宗折价、中粮出货嫌疑。soft_suggest 里敦煌接力窗口、苏垦补涨、招商南油对冲、代糖升级路径也全部记录在案。

不交易条件六条全部未激活：R1 有效（置信度零点七二）、R7 不陈旧（staleness ok）、severity 只有二级、情绪虽是高位震荡但不构成极端贪婪、用户无假期标记。所以今天是”可交易日”，但以控仓为前提——执行池只有两只资源中军、总仓一成三，这就是对”高位震荡第二天”最大的尊重。

数据源审计

R1 到 R7 七个 artifact 全部 ok 且新鲜（R1-R5、R7 为 0908 收盘 + 0909 盘前批次，R6 为 0909 盘后批次，结论与盘前同构并强化）。多源交叉一致：R1 涨停 73 / 跌停 0 / 炸板 37（炸板率 33.64%）与 R3 情绪基线、R2 limit_cpt 对得上；R7 北向 0908 +26.6 亿连续五日净流入与 R6 引用一致。主要缺口：research_summary 聚合文件缺失（orchestrator 未生成），本 plan 由 D1 直接综合 R1-R7，按 degraded 模式出；R3 降级（weflow 永久下线 + hotlist 用 T-1 baseline，置信度 0.70）；emotion_cycle 预计算为降级版 low_test（premium 缺失按保守值），R1 已用 0908 真实指标重算为 high_chop（conf 0.75），以重算为准；fx/商品数据缺失无法独立验证涨价链共识强度；SOX/HSTECH 无数据。这些都不影响主判断链（主判断依赖 R1 涨停/炸板/连板 + R2 主线 + R6 反证 + R7 资金，全部新鲜）。

不确定性与反证自省

最大的不确定还是”双主线资金全是单日爆量”——如果明天开盘一看，黄金、磷化工的板块资金五日序列还是只有今天一个正日，那资源线的”趋势低吸”也要降级，紫金江铜的加仓窗口直接关闭；如果黄金铜股还是不涨停扩散，资源线主线资格都要降级观察。农业线如果亚盛断板，七席霸榜变退潮，观察池里所有农业票降级——亚盛本身就是最灵敏的退潮观察锚。

第二个自我批判点：我把执行池压到两只资源中军，等于把仓位全部押在”铜价新高”这一个叙事上，一旦铜价回调或特朗普关税言论证伪，两只票同时受击。我用低仓位（一成三）和 R6 的”五日资金转正才加仓”闸门来对冲这一点，但必须承认今天的选择是”防守型进攻”，不是”进攻型进攻”——高位震荡第二天，这正是纪律要求的位置。

第三个要正视的：R6 今天生成于盘后批次（15:29），它基于的收盘数据与 R1-R5 盘前一致，结论是”与昨日同构并强化”——也就是说今天盘前该看到的裂缝，收盘后看得更清楚了。本 plan 按盘前口径出（0908 收盘 + 0909 盘前消息），若 0909 盘中实际走势已偏离（例如炸板率破 35%），P2 午盘修订会即时打脸并调整，这不改变本 plan 的盘前决策逻辑。
