一句话结论

震荡分化格局下聚焦贵金属单主线进攻（38%仓位），AI算力留1只业绩验证标的轻仓试探（7%），总仓上限60%。黄金突破4620美元+美伊冲突催化，资金面绝对确认，但R6霸榜警告需紧止损-7%。

市场全景：两条主线，一实一虚

今日市场呈现典型的「资金线vs情绪线」撕裂——贵金属/资源周期手握真金白银的主力流入（黄金+13.58亿、小金属+13亿、稀缺资源+10亿包揽前三），而AI算力+AI电力占据群聊热搜和消息C位，却遭遇科技风格-404亿净流出的冷血现实。

D1 的核心判断：在震荡分化（R1 sentiment=48）+ 情绪冷静偏多（50分）的背景下，资金的话语权大于情绪的话语权。情绪再热，没有资金推动就是空中楼阁；资金再强，没有情绪配合也走不远。贵金属的优势在于——它两者都有（资金92分绝对碾压，情绪55分虽不热但在及格线），而且有地缘冲突+金价创新高的硬核催化。

仓位上限推导链

R1风格信号 = 震荡分化型 → 原始仓位上限 60%
R7北向净流入 = 29.1亿（中性） → 调整 +0%
情绪周期 = 冷静偏多（50分） → 情绪联动上限 60%（不触发逆调节）
R2主线数量 = 2条 → 乘数 1.0
最终仓位上限 = min(60%, 60%, 60%) × 1.0 = 60%

这里有一个反直觉的点：情绪不在冰点也不在贪婪，反而是最适合正常仓位的状态。贪婪时要逆向降仓（怕顶），冰点时要逆向加仓（怕底），中间地带就老老实实跟随系统信号。60% 不高不低，进可攻退可守。

  • 金价若因冲突缓和快速回落，板块面临回调压力

止盈条件：23.33元（+15%减半仓）

不确定性与自我批判

  1. 参考价估算风险：所有止损/止盈/买入价基于 pct_chg 和市场常识估算，交易端执行前必须刷新最新价重新计算。估算偏差可能导致止损位不合理。

  2. R5数据降级：PE/PB/流通市值等基本面数据缺失，意味着估值筛选（PE>100剔除）和市值筛选（<20亿剔除）的执行打了折扣。R6能识别出的高估值标的（昆仑/科锐）已剔除，但可能还有遗漏。

  3. 黄金霸榜的两种解读：R3 distribution_alert 是经典的「热到极点就是顶」信号。但R6也指出「价涨量增非典型霸榜出货」——这是核心分歧点。我们的对策是「信资金但紧止损」，如果真的是顶，-7%止损能保住大部分利润。

  4. AI算力的困境：消息面（阿里800亿/英伟达电力）和情绪面（R3共振第一）都很热，但资金面连续两天说不。历史上这种「故事讲完资金没来」的结局大多是向下。留深信服7%的仓位，既是留个观察窗，也是对「万一这次不一样」的对冲。

  5. 单板块集中度：贵金属4只票占38%仓位，接近40%的单板块上限。如果黄金明天加速上涨，会面临「赚钱但仓位不够」的遗憾；如果黄金回调，会面临「重仓吃大面」的风险。当前配置是在「主线进攻」和「风控约束」之间的平衡。
