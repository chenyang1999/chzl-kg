short_line_thinking_v1 · 短线思维框架 (横切)

归属: 横切 skill — D1 / D2 / E1 / execute 每次决策必先调
目的: 让 agent 先有短线思维，再调数据/算法 — 不让算法视角压倒短线思维
关键差异: 与其他 skill 的区别 — 这个 skill 不调数据，只调”思维框架”

⚠️ 设计的根本原因

agent 倾向于”先看数据再判断”（涨停家数 / 资金流入 / 连板高度）—— 这是 “算法视角”。但短线真正的核心是**“主线梯队 + 卡异动”** —— 这是”短线思维视角”。

调用顺序不可逆:

  1. 先用 short_line_thinking_v1 (5 问)
  2. 再调 R2/R4/R7 数据
  3. 最后用算法

一、5 问 (每次决策必走)

Q1. 主线是什么？

不是”今日涨停最多”。是四个因子齐：

因子数据源判定
题材逻辑R4 事件有具体事件/政策/产业趋势(不是”今天涨得好”)
资金选择R7 + ETF北向/主力/ETF 申购 同步流入
周期位置mainline_lifecycle启动/主升早/中/高潮/退潮
政策窗口R4 + datapro国策/产业政策明确支持

四个都齐 = 真主线。只有一个 = 假主线/电风扇。

电风扇识别：每天换题材、每天新涨停王 = 不赚钱模式。

Q2. 主线梯队结构是什么？

梯队 (陈小群 §2.9 + 92 科比 §3.3.30):
总龙 (上榜早/高度辨识度/带动力)
补涨龙一 (卡总龙短板时间点,率先走出新高度)
补涨龙二 (前排二梯队)
补涨龙三 (中位股)
杂毛 (跟风,无地位)

判定问题：

  • 主线有没有总龙？没总龙 = 主线要断
  • 梯队完整吗？只有总龙没补涨 = 接力不继
  • 补涨龙是哪些？(按”卡总龙短板”时机排序)

Q3. 我在主线什么位置？

主升三浪映射 (用户 2026-09-05 钦定):
一浪 (启动/formation): 首次涨停潮 → 试仓 8%
二浪 (分歧转一致/early_up→mid_up): 首次分歧转强 → 加仓 18%
三浪 (加速赶顶/mid_up→climax 前期): 连板加速 → 持仓不卖 25%
鱼尾 (climax 后期/fade): 高位横盘+缩量 → 必清 0%

Q4. 主线明天怎么走？

信号含义操作
龙头卡 30%/100%/200% 异动主线进入异动博弈期看接力资金能否突破
龙头加速 (一字板/秒板)主线冲刺顶部鱼尾临近, 减仓
龙头断板主线停滞看补涨龙一是否接力
跟风断档 (同日无涨停)主线已死空仓/切新题材
龙头分歧转一致主线延续加仓

Q5. 我的操作？

状态操作
不在主线上任何新闻都不是机会
在主线一浪找前排试仓 (8%)
在主线二浪加仓前排 (18%)
在主线三浪持仓不卖 (25%)
在鱼尾必清不贪
主线已死空仓或切新题材

二、卡异动模型 (陈小群 §2.9.6 原文 + 用户 9-07 实战)

异动节点

A 股龙头的典型异动节点:
30% 涨幅 → 第1 次异动监控
100% 涨幅 → 第二次异动监控 (卡位关键节点)
200% 涨幅 → 第三次异动监控 (临近出货)

卡位判定逻辑

龙头上 30% 异动:
  - 突破 = 主力还要做 → 锁仓
  - 卡不上 = 主力测试,资金出 → 减仓
  龙头上 100% 异动:
  - 突破 = 大资金还有做 → 锁仓等 200%
  - 卡不上 = 大资金开始出货 → 减仓/清仓龙头上 200% 异动:
  - 突破 = 主力最后冲刺 → 鱼尾段,必清
  - 卡不上 = 主力出货确认 → 立刻清仓

实战 (用户 9-07 反馈)

金健米业:
  - 9-07 涨停封死
  - 距100% 异动还差20-30%空间
  - 操作: 锁仓 (等 100% 异动卡位)

万向德农:
  - 9-07 板了 → 锁仓 (前排)
  - 9-07 没板 → 卖 (前排已死)

三、恐高纠偏与挂单策略

不恐高原则 (群主 2026-09-08)

  • 不要因为股价绝对值高而恐高 — 看趋势强度,不看绝对价格
  • 恐高的替代方案: 买板块 ETF,不买个股
  • 高位 = 强的结果,不是卖的理由;趋势破了才是卖的理由
  • 主线龙头加速期,“恐高” = 踏空主升浪

强势股挂单策略 (群主 2026-09-08)

看好的强势股,早盘挂五档确保成交,不要犹豫:

  • 主线核心票,竞价/开盘一字或秒板 → 挂涨停价排单,能排到就是赚到
  • 竞价超预期高开但未一字 → 挂五档买,不纠结几分钱成本
  • 挂单的本质: 用几分钱成本,换”不踏空主线龙头”的确定性
  • 反过来: 不看好的票,一分钱都嫌贵

适用范围: 仅适用于主线核心龙头/补涨龙前排,不适用于中位杂毛。

四、禁止清单 (vs 数据/算法视角)

视角❌ 错的✅ 对的
涨停家数”今天涨停最多就是主线”4 因子齐才信
资金流入”主力净流入就做”看 ETF/北向/产业资本同向
连板高度”7板比3板强”看梯队完整度
新闻催化”今天有新闻就买”看逻辑 + 资金 + 周期
算法判定”算法算出 promote 就买”算法只生成 warning, 由人快速通道顶

七、自我约束 (agent 反思)

每次 agent 写完输出, 必须自查:

  • ❌ 我有没有用”涨停家数”代替”主线判定”?
  • ❌ 我有没有把”算法算出 promote”当成”该买”?
  • ❌ 我有没有忽略”卡异动节点”?
  • ❌ 我是不是因为一只票”跌下来/在水下/便宜了”就想低吸埋伏? — LLM 天然带均值回归先验(主流语料把追涨描述成赌博、把抄底描述成理性),这是 agent 偏置,不是交易系统的信号。
  • ✅ 我的输出有没有”主线 + 梯队 + 阶段 + 卡异动”4 个维度?

少一个 = 投骰子,不赚钱。

低吸术语硬约束 (2026-10-14 用户纠偏固化)

用户账本事实(钦定,勿再漂移):

  • 打板 64% 胜率 / +33k — 正 α
  • 强势低吸 55% 胜率 / +9k — 正 α;定义 = 预判该票当日会涨停,哪怕高开 5% 买进也算低(相对涨停价仍低);或盘中砸深水能 V 起的强势票
  • 半路 35% 胜率 / -47k — 负 α,禁止
  • 弱势低吸(抄底) 37% 胜率 / -35k — 负 α,禁止;定义 = 大跌后接飞刀/无主线日埋伏等明天

agent 输出任何”低吸/埋伏/捡便宜/跌出机会”类建议前,必须过 3 问,任一不满足 = 不许给代码,改归类为”抄底”并按负 α 处理:

  1. 这只票今天/明天有没有涨停预期?它是不是主线总龙/补涨龙/低位前排?
  2. 当前情绪周期允许开仓吗?(退潮/主跌期:禁止一切低吸,空仓)
  3. 我推荐它的理由是”强势延续”还是”跌多了该反弹”?后者 = 均值回归幻觉,直接否。

特别警惕时点:尾盘 14:00 后问”埋伏进去等明天有没有收益”——这是禁止清单 #9 late_speculation + #11 overnight_bad_streak 的组合形态,默认回答是”不买”,除非次日有已核实的硬事件催化 + 竞价确认路径已写明。
