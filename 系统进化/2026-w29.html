二、成功经验 (3 条)

1. P1 竞价校准挽救 07-13 崩溃退潮日

概要: 07-13 P1 正确 defer 了中国卫星(高开+3.87%超限+参考价错误)和兆易创新(低开-5.23%跌破buy_zone), 使执行池从 5 只缩至 3 只, 避免了 -10% 跌停级的亏损。

验证数据:

  • 中国卫星 P1 defer → 收盘+1.38% (盘中曾+7.84%但回落)
  • 兆易创新 P1 defer → 收盘-10%跌停, 豁免 -10% 亏损
  • 航天发展(P2 收紧止损至-3%) → 收盘-10.02%跌停

可复用: 竞价价格偏离(高开>3%或低开>5%)的 defer 机制有效, 应持续保持。

2. R6 反证系统在极端行情下的高兑现率

概要: R6 本周 71% 兑现率, 特别在 07-13 崩溃退潮日达到 100% 满分。R6 成功预警了:

  • 存储资金流出(兆易-10%/香农-20%)
  • 香农芯创 V2 估值陷阱(龙虎榜净卖-24.87亿)
  • 华天科技 lhb_bull_trap(跌停+机构净卖-11.1亿)
  • 赛力斯反证监控(-10%跌停)

可复用: R6 在资金面+估值面+龙虎榜三源交叉验证时的准确率极高, 应保持并加强。

3. 中医药防御主线在风格切换中的正确响应

概要: 07-14 AI硬件雪崩后, 系统正确识别中医药作为防御主线(哈药2连板, 板块龙虎榜8只上榜), 成功从科技成长切换到医药防御。

验证数据: 哈药+9.97% 2连板, 太极集团低吸机会存在, 华东医药+2.67%, 复星医药+1.09%

三、失败教训 (5 条)

1. R1 风格判断双向误判 (阈值缺失)

问题: 07-13 判震荡分化型→实际崩溃退潮(仓位上限55%过高), 07-14 判崩溃退潮型→实际震荡修复(仓位上限20%过低)。同一周内两次方向相反的误判。

根因: R1 缺少「次日竞价情绪校准」和「开盘30min炸板率校准」两个关键前置信号。

修复: 详见 PATCH-001 (analyze_style_v1)

2. IPO 抽血效应 > 催化效应 (长鑫IPO)

问题: 长鑫科技 IPO 定价8.66元低于预期, 触发存储板块系统性杀跌(华天-10%跌停, 佰维-15%, 兆易-2.09%)。我方 R2 将其视为利好, 重仓存储。

根因: R7 资金面未识别 IPO 前抽血效应; R4 消息面未把长鑫定价作为独立风险事件

修复: 详见 PATCH-006 (analyze_capital_flow_v1) + PREF-004 (ipo_absorption_protection)

3. 同 β 主线对冲失效 (双主线=单一敞口)

问题: 07-15 双主线(PCB/光模块 + 存储)同为科技成长, 长鑫抽血 + 数据中心成本预警导致双主线同时回调, 集中度放大风险。

根因: R2 未做「跨风格覆盖」检查, 同为科技成长的”双主线”实为单一 β 风险敞口

修复: 详见 PATCH-002 (analyze_main_sectors_v1) + PREF-003 (sector_concentration 跨风格约束)

4. 漏抓 P0 级催化源 (政策文件+顶刊论文)

问题: 07-15 漏抓两条高置信度催化:

  • 国务院《国民健康”十五五”规划》→ 创新药全线大涨
  • 宇树机器人 Nature 论文(首次活体手术) → 机器人板块大涨
  • 若提前识别, 可提前布局两条独立 alpha

根因: R4 消息面源仅限于微信公众平台/财经新闻/群聊, 未覆盖 gov.cn 和 Nature/Science

修复: 详见 PATCH-003 (analyze_news_impact_v1) + PREF-005 (news_sources)

5. P2 功能缺失 (升格+止损+数据验证)

问题: P2 本周暴露 3 项缺失:

  • 韦尔+4.68%/埃斯顿+6.51% 观察池未升格 → 错失 +3% 潜在收益
  • 紫光国微-7.65% 未触发硬止损扫描
  • 哈药 pre_close 4.49 被误读为午盘价格 → 错误结论

根因: P2 当前仅做”打脸检测”和”止损建议”, 无升格/硬止损扫描/数据验证

修复: 详见 PATCH-005 (midday_amendment_v1)
