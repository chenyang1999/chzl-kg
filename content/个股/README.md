# 个股(R5 + 你手写)

**你手写的**:每只有跟踪的股票开一个子目录 `{代码}/`,写 `逻辑.md` —— 你的核心投资逻辑。

**R5 产出**:每天早晨 R5 情报深挖 Agent 会在每只 R2 圈定的龙头下写 `YYYYMMDD_画像.md`(六维画像)。

**目录结构**:
```
个股/
├── 002050/                # 三花智控
│   ├── 逻辑.md            # 你手写核心逻辑(不动)
│   ├── 20260701_画像.md   # R5 每日产出
│   ├── 20260702_画像.md
│   └── 20260703_画像.md
├── 300124/                # 汇川技术
│   └── ...
```

**规格**:见 `docs/agents/R5-情报深挖Agent.md`
