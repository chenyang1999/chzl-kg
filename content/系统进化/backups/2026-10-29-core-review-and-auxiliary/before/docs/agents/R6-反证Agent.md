## 4. 六类反证模式(简表)

1. 数据源冲突(soft)
2. 一致性检查(strong)
3. 估值 × 主线临界(strong)
4. 历史类比(soft,依赖历史库)
5. 昨日预期错误连锁(strong,依赖复盘)
6. **霸榜出货硬约束(hard reject,唯一硬否决权)**

## 6. 降级路径

| 上游 Agent 死了 | 应对 |
|-----------------|------|
| R1 缺失 | 跳过风格一致性检查,其他模式照常 |
| R2 缺失 | 无核心票,R6 无对象 → 出"上游数据缺失,今日不出反证" |
| R3 缺失 | 跳过共振检查 |
| R4 缺失 | 跳过消息一致性检查 |
| R5 缺失 | 跳过估值/技术反证 |
| 全部 R1-R5 缺失 | R6 拒绝出产出 |

---

## 7. 红线(强制)

1. ❌ 不抓新数据(只读上游产出)
2. ❌ 不给正向结论
3. ❌ 除模式六外不允许硬否决
4. ❌ 反证数量 <5 时,出 "今日反面证据不足"(不硬凑)
5. ✅ 必须每天产出(即使全绿,输出"今日无重大反面证据")
6. ✅ 每条反证必须带 severity + evidence[] + suggestion
