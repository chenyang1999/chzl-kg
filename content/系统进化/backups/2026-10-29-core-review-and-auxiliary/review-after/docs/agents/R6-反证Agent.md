## 4. 正式审核范围与反证模式

正式审核必需：模式1的资金与消息交叉、模式2风格一致性、模式6出货风险、模式7财务合规。按对象及观察窗口核必要证据；partial中的真实对象可继续审查，缺必要证据仍未完成。模式3估值、模式4历史类比、模式5昨日兑现及其他辅助扩展可局部降级，不抹掉已核结果。

仅辅助项目缺失不阻必要审核完成，但必须保留局部降级及缺口；任何必要项目未完成，不得声称全票通过。正式完成、未发现反面证据、有效硬否决和交易许可分别表达。具体覆盖与字段语义以`skills/analyze_devil_advocate_v1/SKILL.md`当前正式范围为准。

1. 数据源冲突(soft)
2. 一致性检查(strong)
3. 估值 × 主线临界(strong)
4. 历史类比(soft,依赖历史库)
5. 昨日预期错误连锁(strong,依赖复盘)
6. **霸榜出货硬约束（保留原alert与资金条件）**
7. **财务合规（保留已有财务红旗/合规硬否决）**

高位/高度标签本身只提示风险，不单独新增硬否决；若已有出货或财务合规风险，仍按其原条件处理。不改预算、数值阈值、禁止替补或D1/执行层门禁。

## 6. 降级路径

| 上游 Agent 死了 | 应对 |
|-----------------|------|
| R1 缺失 | 风格一致性未完成，其他有据模式继续 |
| R2 缺失 | 无核心票,R6 无对象 → 出"上游数据缺失,今日不出反证" |
| R3 缺失 | 一般共振可降级；必要alert结果缺失时出货审核未完成 |
| R4 缺失 | 消息交叉未完成，其他模式继续 |
| R5 缺失 | 估值可局部降级；必要财务合规/资金确认缺失仍未完成 |
| 全部 R1-R5 缺失 | R6 拒绝出产出 |

## 7. 红线(强制)

1. ❌ 不抓新数据(只读上游产出)
2. ❌ 不给正向结论
3. ❌ 不因高位或辅助缺口新增硬否决；模式6出货与模式7已有财务合规硬否决保留
4. ❌ 不硬凑反面条数；零发现不等于零审核或自动通过
5. ✅ 必须每天产出并声明必要审核覆盖；未完成不写全票通过
6. ✅ 每条反证必须带 severity + evidence[] + suggestion
