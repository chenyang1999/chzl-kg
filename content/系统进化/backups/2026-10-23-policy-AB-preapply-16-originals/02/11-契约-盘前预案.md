# watchlist_plan.json 标准Schema说明

> 路径：`data/runtime/watchlist_plan_YYYYMMDD.json`
> 交易Agent网页和执行Agent都依赖这份结构化数据，**必须严格遵守字段名和枚举值**

---

## 顶级字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `trade_date` | string | ✅ | 交易日，格式 `YYYYMMDD` 如 `"20260629"` |
| `mode` | string | ✅ | `"live"` 实盘 / `"dry_run"` 回测 |
| `agent_name` | string | ✅ 固定 | `"盘前预案 Agent / Stock Selection & Setup Agent / Alpha-Setup Agent"` |
| `generated_at` | string | ✅ | ISO格式时间 `"2026-06-29T08:30:00+08:00"` |
| `trading_style` | string | ✅ 固定 | `"mainline_right_side_with_trend_pullback"`（主线进攻+右侧低吸） |
| `autonomous_trading_enabled` | bool | ✅ | `true` 允许自动交易 / `false` 需人工确认 |
| `requires_user_confirmation` | bool | ✅ | `false` 自动执行 / `true` 需要确认 |
| `data_sources` | object | ✅ | 数据源审计，见下文 |
| `market_context` | object | ✅ | 市场环境分析，见下文 |
| `risk_limits` | object | ✅ | 风控限额，见下文 |
| `portfolio_rebalance` | object | ✅ | 调仓计划，见下文 |
| `sector_core_watchlist` | array | ✅ | 板块核心票列表，见下文 |
| `execution_pool` | array | ✅ | 当前可执行池（已持有/待买入已在计划中），每个元素是 **StockEntry** |
| `watch_pool` | array | ✅ | 观察池（备选，不在今日计划买入但跟踪），每个元素是 **StockEntry** |
| `rejected` | array | ✅ | 否决标的（可以为空） |
| `research_anchor_only` | array | ✅ | 仅研究不交易（可以为空） |

**完整标准数据源列表（全系统必须全部写上）：**

## risk_limits 风控限额结构

```json
"risk_limits": {
  "target_total_position_pct": 0.75,      // 目标总仓位 小数 0.75 = 75%
  "max_positions": 5,                   // 最大持仓数量 只
  "max_buy_orders_per_day": 4,         // 每日最大买单数量
  "max_orders_per_symbol_per_day": 2,  // 单只股票每日最大交易次数
  "block_prefixes": [],                // 禁止买入代码前缀 如 ["300", "688", "920"]
  "block_st": false,                   // 是否禁止ST股
  "kill_switch_file": "data/runtime/KILL_SWITCH"  // 紧急停止开关文件
}
```

**风控铁律：**
- `target_total_position_pct` ≤ 0.80 (80%)
- `max_positions` ≤ 5-6
- `max_single_stock_pct` ≤ 0.15 (15%) （在StockEntry里）
- `max_single_sector_pct` ≤ 0.40 (40%)

## StockEntry 单个标的结构（execution_pool / watch_pool）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ts_code` | string | ✅ | 带后缀 `000636.SZ` / `600522.SH` |
| `name` | string | ✅ | 中文名称 |
| `theme` | string | ✅ | 板块/题材 `"半导体材料/LDS"` |
| `role` | string enum | ✅ | **必须用枚举值**：<br>`leader` - 龙头<br>`core_midcap` - 核心大中盘<br>`core_largecap` - 核心大盘<br>`elastic_core` - 弹性核心（可加仓可减仓）<br>`watch_elastic` - 观察池弹性标的<br>`watch` - 仅观察<br>`exit` - 今日开盘要卖出清仓<br>`exit_if_no_break` - 如果不创新高就卖出 |
| `score` | int 0-100 | ✅ | 综合评分 |
| `plan_status` | string enum | ✅ | **必须用枚举值**：<br>`execution_pool_hold` - 持有，不开新仓<br>`execution_pool_hold_add_on_pullback` - 持有，回踩可加仓<br>`execution_pool_hold_partial_take` - 持有，高开可减仓<br>`execution_pool_exit_at_open` - 开盘卖出<br>`execution_pool_exit_if_no_new_high` - 不创新高则卖出<br>`watch_pool_wait_for_entry` - 等待买入机会<br>`watch_pool_only` - 仅观察不计划买入 |
| `auto_trade_enabled` | bool | ✅ | 是否允许自动交易 |
| `requires_user_confirmation` | bool |  | 默认`false`，退出/不确定标`true` |
| `max_position_pct` | float | ✅ | **小数** 最大仓位 `0.14` = 14% |
| `is_st` | bool | ✅ | 是否ST |
| `reason` | string | ✅ | 买入/持有逻辑说明（一句话） |
| `stop_loss` | float | ✅ | 止损价 |
| `take_profit` | float | ✅ | 止盈价 |
| `theme` | string | ✅ | 题材归属 |
| `trigger_price` | object | ✅ | 触发价格字典，见下文 |
| `entry_rules` | array | ✅ | 入场规则列表，每个元素是EntryRule |
| `sise_red_count` | int | ✅ | 四色四量 红色转强计数 0-5 |
| `sise_note` | string | ✅ | 技术形态说明 |
| `ts_code` | string | ✅ | `000000.SZ` 格式 |

### trigger_price 触发价格

```json
"trigger_price": {
  "low_absorption": {              // 低吸触发（已经有底仓，回踩加仓）
    "price": 83.0,                 // 触发价格
    "confirm": 83.5,               // 确认价格（站稳）
    "max_ask": 84.66               // 最高买价 ≤ 这个价才追
  },
  "breakout": {                     // 突破触发（高开突破箱体）
    "price": 89.0,
    "confirm": 89.5,
    "max_ask": 91.67
  }
}
```
- 可以只给一个（如持有仅需要breakout）
- 清仓标的可以是 `{}` 空

### EntryRule 入场规则（单个买入条件）

```json
{
  "type": "trend_pullback_buy",        // 枚举：trend_pullback_buy / leader_breakout
  "trigger_price": 83.0,             // 触发价
  "max_premium_pct": 0.02,            // 最高允许溢价买入 2%
  "position_pct": 0.06,              // 此次买入仓位（总max_position_pct里占比）
  "entry_target_price": 84.0,         // 目标成交均价
  "confirm_price": 83.5,              // 确认站稳价格
  "max_acceptable_ask": 84.66,        // 最高买一价不超过这个才能成交
  "execution_logic": "回踩MA20(82.0)附近缩量站稳加仓...",  // 执行说明
  "derivation_reason": "MA20支撑位，当前87.13距MA20有空间，回踩是加仓机会",  // 推导说明
  "buy_zone": [83.0, 83.5],           // 买入区间 [low, high]
  "pullback_zone": [83.0, 83.5],     // 回踩区间（同buy_zone）
  "reclaim_price": 83.5              //  reclaim价格
}
```

**type 枚举值（必须正确）：**
- `trend_pullback_buy` - 趋势股回踩低吸买入
- `leader_breakout` - 龙头突破买入
- 已持有不需要加仓的 `entry_rules` 是空数组 `[]`

## ExitRule 出场规则（单个卖出条件）

每个StockEntry都必须有 `exit_rules` 数组，包含至少一条硬止损。多条按 `priority` 从小到大触发。

```json
{
  "type": "stop_loss_break",         // 枚举，见下文
  "trigger_price": 23.5,              // 硬价位触发（null 表示无硬价位，仅条件触发）
  "trigger_condition": "非主线跌1.5%且30分钟未收回",  // 复杂条件（可选，仅 type=intraday_break_exit / rebound_reduce / eod_forced_exit 用）
  "quantity_pct": 1.0,                // 卖出比例 0-1（1.0=全清，0.5=减半）
  "priority": 1,                      // 优先级 1最高
  "reason": "跌破止损"               // 说明
}
```

**type 枚举值（必须正确）：**
- `stop_loss_break` - 跌破硬止损价立即全清（priority=1 必填）
- `take_profit_hit` - 触及目标价分批止盈
- `intraday_break_exit` - 日内板块崩溢（板块跌X%且个股Y分钟未收回）快速止损
- `rebound_reduce` - 现有持仓反弹至触发价减仓（用于换仓，浮亏但不愿低卖）
- `rebound_reduce_2` - 强反弹二次减仓（把剩余仓位也清掉）
- `eod_forced_exit` - 尾盘强制减/清仓（防深套，`trigger_price=null`，`trigger_condition` 描述条件）

**exit_rules 使用规范：**
- 每个 StockEntry 必须至少有 1 条 `type=stop_loss_break` 且 `priority=1`
- `plan_status=execution_pool_exit_at_open` 的持仓必须给出多阶反弹卖出（`rebound_reduce` + `rebound_reduce_2` + `eod_forced_exit`）
- `plan_status=execution_pool_hold_add_on_pullback` 的持仓一般 3 条：`stop_loss_break` + `intraday_break_exit`(减1/2) + `take_profit_hit`(减1/2)

## do_T_state 做 T 状态机（可选字段，用于持仓做 T 场景）

StockEntry 可选带 `do_T_state` 字段，用于日内高抛低吸(做 T)：

```json
"do_T_state": {
  "enabled": true,                   // 是否允许做 T
  "base_qty": 2400,                   // 基础仓位（不动，不参与做 T）
  "mobile_qty": 800,                  // 机动仓位（用于做 T）
  "base_mobile_ratio": 0.75,          // 基础仓 : 总仓 比例（0.75=不动的占 3/4）
  "max_t_rounds_per_day": 1,          // 单日最大做 T 轮次
  "sell_high_price": 26.5,            // 高抛价（>=此价卖出 mobile_qty）
  "buy_low_price": 25.2,              // 低吸价（<=此价买回 mobile_qty）
  "abort_on_breakout": true           // 放量突破时放弃反 T（防卖飞）
}
```

**做 T 铁律：**
- T+1 硬约束（当日买回的股票不能当日卖）
- `base_mobile_ratio` ≥ 0.6（至少 60% 是底仓不参与做 T）
- 被放量突破时必须放弃反 T（`abort_on_breakout=true`）
- 一日一轮 T，不循环

## 验证通过要点

1. **所有枚举值必须严格匹配** — 不能用中文「核心持仓」必须用 `core_midcap`
2. **仓位必须是小数** — 14% = `0.14` 不能是 `14`
3. **日期格式必须正确** — `YYYYMMDD` 如 `20260629`
4. **ts_code必须带后缀** — `.SZ`/`.SH`
5. **JSON语法必须正确** — 逗号不能少也不能多，括号配对
