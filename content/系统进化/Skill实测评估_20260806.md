## 3. 各 skill 详细点评

### 🥇 行业轮动监控（最佳配套）

**跑出来的输出**（节选）：
- Step 2 宏观五支柱评估：LPR/MLF/RRR/社融/CPI/PPI/PMI 全覆盖
- 周期判断：复苏期前段
- 行业配置：超配科技成长/低配地产链
- 风险识别：4 个失效触发条件

**亮点**：
- **配套最完整**——`SKILL.md` + `macro-sector-framework.md` (8.8KB) + `output-template.md` (4.2KB) 三件套
- 框架从"指标矩阵"到"行业轮动图谱"到"历史行业表现"都有
- 输出**结构化程度最高**（仪表盘/打分/置信度）

**短板**：
- 框架细节多，LLM 跑起来 token 消耗大
- 需要 LLM 对宏观数据有判断（不能纯规则化）

### 🥇 催化剂日历（最实用）

**跑出来的输出**（节选）：
- 4 周分类：财报期/公司事件/行业会议/宏观事件
- 关键事件：8/19 中际旭创中报、8/22 寒武纪中报、8/15 兆易创新解禁
- 美联储议息、苹果/英伟达/华为产业链节点

**亮点**：
- **最适合用户风格的 skill**——打板派需要知道"未来几天要发生什么"
- 4 周时间窗口刚好覆盖一次中报披露周期
- 框架直接可挂 cron 跑（每周一次）

**短板**：
- 没有 output-template（需要 LLM 自创格式）
- 缺个股级深度（只到事件级，没到影响/受益标的）

### 🥈 财报前瞻（中规中矩）

**跑出来的输出**（节选）：
- 选 中际旭创（300308.SZ）
- 4 步：收集共识/关键指标/情景分析/催化剂清单
- 三个情景：Bull/Base/Bear + 股价反应

**亮点**：
- 情景分析框架清晰
- 关键指标 + 共识/分歧分离
- 中际旭创的 800G/1.6T/毛利率三问切中行业核心

**短板**：
- 只有 SKILL.md，没 references 模板
- 部分数据标"待补充"（LLM 跑时无法实时取 tushare）
- 跟用户的"打板派"风格不完全匹配（财报前瞻更适合中长线持有）

### 🥈 财务报表深度解读（最专业）

**跑出来的输出**（节选）：
- 选 深圳华强（000062.SZ）
- 三表勾稽 + 杜邦拆解 + 10+ 造假红旗
- 财务健康度评分

**亮点**：
- **财务框架最系统**——三表勾稽、盈利质量、杜邦、造假红线四件套
- 输出格式与卖方研报接近
- 适合做"持股期"或"尽调期"的深度分析

**短板**：
- **跟用户风格不匹配**——用户是打板派，不看杜邦
- 输出太重（15KB），对短线交易过载
- 财务数据需要 tushare 实时取数，LLM 单跑只能给框架

## 4. 按用户偏好的最佳使用建议

**用户画像**：
- 打板派老手 + 创业板 20cm 强势低吸
- 时间极紧（清华博士 + 投研）
- 老登股解禁后中短线波段
- 要信早信主线第一天

**最佳使用组合**：

```
📅 每日 07:00  催化剂日历 (未来4周)   → 知道近期要发生什么
📅 每周一 07:30 行业轮动监控          → 知道当前在哪条主线上
📅 中报披露前3日 财报前瞻            → 知道具体票的中报怎么走
📅 持仓股有疑虑时 财务报表深度解读    → 验证财务质量，决定去留
```

## 5. 核心发现

### ✅ 4 个 skill 都是"结构化思考框架"，不是数据脚本
- 价值在于"统一问什么、按什么顺序、产出什么格式"
- 不提供数据，提供**思维脚手架**
- 适合挂 cron 让 sub-agent 跑

### ⚠️ Skill 跟用户现有体系的关系
- **不冲突**：4 个 skill 都是新能力，不替代现有 R1-R7/D1/E1
- **互补**：
  - 催化剂日历 = 给盘前预案加事件时间线
  - 行业轮动监控 = 给 R1 风格研判加宏观维度
  - 财报前瞻 = 给 R5 个股画像加中报维度
  - 财务深度解读 = 给 R5 加财务质量过滤

### ❌ 局限性
- **数据靠外部取**——LLM 跑 skill 时若无 tushare/iwencai 实时数据，结果会是"框架完整 + 数据待补"
- **耗时较长**——4 个 skill 全部跑完花了 6 分 13 秒
- **需要 LLM 驱动**——纯规则版跑不出这种质量

### 📌 配套完整度排名
1. 行业轮动监控（双 references） > 财务报表深度解读（financial-statement/ 子目录）
2. 财报前瞻（仅 SKILL.md） < 催化剂日历（仅 SKILL.md）

**建议**：给财报前瞻和催化剂日历补 output-template.md，可显著提升输出稳定性。

---

## 6. 一页纸总结

**4 个 skill 全部实测可用，框架质量好于预期。**

**最值得用的 2 个**（按用户风格）：
1. **催化剂日历**：打板派最需要"知道近期要发生什么"，4 周时间窗口刚好覆盖中报周期
2. **行业轮动监控**：补足 R1 风格研判的宏观维度

**次值得用**：
- 财报前瞻：中报季才用，平时不需要
- 财务深度解读：持仓有疑虑时再调，跟打板风格不日常

**配套建议**：给催化剂日历 + 财报前瞻补 output-template.md，能稳定输出。

**测试产物**（4 份）保留在 `/tmp/test_*.md`，可直接作为各 skill 跑通的样例。
