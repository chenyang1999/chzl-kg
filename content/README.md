## 日常怎么读

按业务日期在相应栏目查找；日期只是检索条件，不是交付有效性证明。

1. [风格研判](投研交易/风格研判/) → [主线研判](投研交易/主线研判/)：先看市场背景与主要方向。
2. [消息面](投研交易/消息面/) · [催化剂](投研交易/催化剂/) · [事件追踪](投研交易/事件追踪/)：核对事件、来源与后续变化。
3. [资金面](投研交易/资金面/) · [个股画像](投研交易/个股画像/) · [反证](投研交易/反证/)：交叉检查证据与反面条件。
4. [盘前预案](投研交易/盘前预案/) → [竞价判断](投研交易/竞价判断/) → [午盘修订](投研交易/午盘修订/)：按时点看对应版本，不能把不同阶段当重复件。
5. [复盘记录](投研交易/复盘记录/)：回看当日判断与偏差。文件可能含受限信息，对外引用需另行审查。

补充入口：[扩池](投研交易/扩池/) · [个股股性](投研交易/个股股性/) · [题材心智锚](投研交易/题材心智锚/) · [数据源台账](投研交易/数据源台账/)。专题材料还可从 [个股](个股/) · [板块](板块/) · [题材库](题材库/) 进入。

### 为什么日常目录不能直接改名

源码有明确的原路径消费者，例如：

- [研究产物检查](../scripts/research/pipeline_artifacts.py) 将研究单元映射到 `投研交易/<栏目>/<业务日期>.md`。
- [历史预案解析](../src/review/plan_text_parse.py) 读取原路径的盘前预案。
- [周度复盘准备](../src/review/weekly_evolution_prep.py) 引用系统进化中的周度记录。

这些是静态源码证据，不代表本次运行过相关任务。移动路径前须检查生产者、消费者、人工入口与回滚方案，并单独签核；本次未迁移日常研究产出目录。

## LLM Wiki：源库，不是待删的日报副本

`chzl/` 是已有的 LLM Wiki 工作区，不是误嵌套出来的第二个 `chzl_kg/`。

- `chzl/raw/sources/` 留存摄入源与历史快照；部分入口是指回原目录的符号链接。快照与活动研究文件即使字节相同，也有来源追踪用途。
- `chzl/wiki/` 承载知识页与索引，阅读从 [Wiki 索引](chzl/wiki/index.md) 开始；索引和来源记录不等于最新部署状态。
- 研究范围可参看 [purpose.md](chzl/purpose.md)，其历史说明不覆盖当前系统契约。
- `schema.md`、插件状态与编辑器配置本组均未更改。含“cache”字样的状态文件、聊天和页面历史不自动视为可删除缓存。
- 源库及派生知识可能继承原材料的私密性；本页不提供私密源文件清单，也不授权整库同步或公开发布。
