# A股短线黑话词典

> 不搞学术定义，只写盘面上怎么用。每个词标出处（五人＝北京炒家/陈小群/92科比/涅槃重升/一瞬流光；养家＝炒股养家；纪律＝新生代游资交易纪律）。

## 一、情绪周期节点（最核心，先背）

| 词 | 定义 | 该做什么 | 禁止 |
|---|---|---|---|
| **低位试错** | 老题材冰点、新题材轮动、无主线 | 打首板、低位补涨、切新题材、轻仓试错 | 猛干高位龙、重仓 |
| **主升** | 龙头打高度、主线确认、普涨 | 猛干龙头（任何位置进都对）、连板补涨、低位潜伏、分歧敢买 | 支线、暗线、自己选的龙 |
| **高位震荡** | 龙头断板、亏钱效应出现、低位补涨 | 落袋、轻仓、龙头未死挖低位 | 博弈穿越（约只有25%成功，性价比低） |
| **主跌** | 龙头人气股大跌、亏钱扩散 | 空仓为主、连冰后尾盘试错、切新题材 | 小反抽当主升、情绪票逆势 |
| **补跌** | 连板各种大面且继续杀，强转弱就大跌 | 不碰情绪票，除非指数共振大阳 | 超跌反弹满仓 |

**边界词**：
- **退潮**＝情绪从高位往下、亏钱扩散。**冰点**＝情绪最低点（涨停少、跌停多、晋级率个位数）。**修复**＝冰点次日回暖。
- **穿越**＝高位震荡后二波继续打高度（≈25%）。默认不赌穿越。
- 养家最狠的一句："主跌第一天最狠，第二天还杀才尾盘试，第三天修复回试错"。量化印证：主跌平均只持续 1.7 天。

## 二、龙头与角色体系（科比三格 + 细分）

核心世界观只有三格：**龙头 / 补涨 / 切换**。

| 词 | 定义 | 怎么用 |
|---|---|---|
| **总龙 / 龙一** | 主线里带跟风、区间涨幅+累计板靠前，允许断板 | 有总龙不做分龙；主升可锁仓到巅峰 |
| **分龙** | 并行支线里相对最高 | 有主线不做支线 |
| **补涨龙** | 龙一已有4板或首次断板后才启动、晋级2板 | 只补主流、龙头没走完；最佳窗口是龙头急拉后前一两次分歧转强 |
| **伴生龙** | 晚于龙一、连板更干净、市值更大 | 湖南白银vs白银有色——连板好看但辨识度不是它，别上当 |
| **卡位龙** | 波段前几天就上车2-3板，没走成龙一龙二 | 迷茫期幻想它变总龙极难 |
| **龙二** | 同波第二，得分≥龙一55% | 总龙上不了车时的备选，仓位低于总龙 |
| **先锋** | 主线最早打2板 | 点火信号，不等于已是总龙 |
| **中军** | 流通市值大、一提行业就想到的名企 | 下午打板优先中军；抱团票当中军/趋势，不当连板总龙 |
| **老龙 / 新龙** | 上一波龙一还在但高度被新人超过 | 总龙熄火、题材未退潮→立刻换新龙。过气龙头不如狗 |
| **穿越** | 同一票两波都是龙一、二波创新高 | 高位震荡默认不赌 |
| **高度试探** | 连板≥5、跟风<4、换手偏低 | 兴业科技、海鸥住工——禁止当总龙 |
| **趋势大妖** | 峰值连板≤3、区间涨幅≥80% | 看日线/周线，不看连板天梯 |
| **低位前排** | 主线里首板/二板没晋级 | 试错期、弱市复制赚钱效应用 |
| **情绪股** | 波动能大幅影响市场人气；缩量一字连板多是情绪股非龙头 | 少做，直上直下 |

**龙头认定过3条才算数**（数板不算）：①高度/涨幅有辨识度、市场公认；②逻辑硬、最好映射业绩或国策；③能带动板块（光杆司令走不远）；④容量换手够（能上下车）。

## 三、手法与板型

| 词 | 定义 | 关键约束 |
|---|---|---|
| **打板** | 涨停价买入（板上确认） | 出发点是"今天封住、享明天溢价"，不是"今天赚几个点" |
| **扫板** | 涨停瞬间主动一笔打上去 | 少而精 |
| **排板** | 挂涨停价排队等成交 | 可多分，避免买不到该满不满 |
| **半路** | 平开放量突破压力位跟随买入 | 量难确定，看不准改排板（科比/涅槃半路少做的原因） |
| **低吸** | 预判该票**当日会涨停**、哪怕高开5点买进也算低（相对涨停价仍低）；或盘中砸深水能V起 | **≠抄底**。强势低吸是正α（55%胜率），弱势低吸/抄底是负α（37%胜率−35k） |
| **抄底** | 大跌后接飞刀 | 负α，禁止 |
| **翘板** | 跌停价买入博反包 | 非趋势/非硬逻辑票，次日不涨停清空 |
| **核按钮** | 跌停价砸盘恐慌卖 | 高位核了对低位影响不大，可转做低位补涨，别去接核按钮本身 |
| **反核** | 跌停打开时接（陈小群成名技：中交地产、特力A） | 只留总龙锁仓模板，学习期关闭 |
| **秒拉板** | 一笔单从零轴拉到涨停 | 无板块效应不打（板块30票就2红=封不住） |
| **回封板** | 炸板后回封 | 多次打开、尾盘才封=弱 |
| **换手板** | 5-8点横够半小时再上板 | 可扫，封板率高 |
| **尾盘板** | 14:30后点火板 | 尽量不打（投机板） |
| **中军板** | 板块名企/行业领头羊 | 下午若打板优先 |
| **首/二/三板** | 连板数 | 首板是最便宜入口 |
| **缩量板** | 一字/缩量连板 | 情绪股，少做（换手出妖股，死亡换手70%+次日难弱转强） |
| **放量板** | 充分换手上板 | 龙头包容性来源 |
| **反包** | 总龙首阴后再次涨停 | 反包=行情继续开关；被按=准备调整 |
| **反包二板** | 反包后的第二个板 | 大资金舒适区（反包一板可能闷杀） |

## 四、状态与信号

| 词 | 定义 |
|---|---|
| **炸板** | 涨停被砸开。炸板率 = 炸板/(涨停+炸板) |
| **封板** | 涨停封住 |
| **断板** | 连板终止 |
| **晋级** | 次日继续涨停（1进2、2进3…晋级率） |
| **溢价** | 涨停股次日高开程度（昨日涨停今日表现=赚钱效应核心指标） |
| **赚钱效应** | 追涨能赚钱→刺激资金重复追涨→推高情绪 |
| **亏钱效应** | 追涨亏钱→退潮。养家：买入倾向来自赚钱效应，卖出倾向来自亏钱效应 |
| **弱转强** | 烂板/低预期票次日表现优异。最好平开/低开后买盘买上去，别竞价高开（太刻意=做盘） |
| **强转弱** | 该强不强。养家：该弱不弱视为强，该强不强视为弱→后者直接放弃 |
| **分歧** | 多空激烈。**买入分歧** |
| **一致** | 人人看多。**卖出一致**（一致加速人人觉得稳=卖出区） |
| **加速** | 连板加速一字/秒板 |
| **辨识度** | 市场共同认定的核心地位。北京炒家：带动力+批量板+指数共振 |
| **预期差** | 逻辑/业绩超预期空间。陈小群：预期差越大走得越好 |
| **天地板** | 涨停→跌停 |
| **地天板** | 跌停→涨停（合力很强才可打板） |
| **合力** | 全市场资金共同推动。大单砸而封单增=合力还在；没市场合力的抱团=接盘 |

## 五、资金与风格

| 词 | 定义 | 出现节点 |
|---|---|---|
| **市场风格** | 市场当下愿意为什么付钱（低价/趋势/连板/名字梗） | 每天第一问 |
| **老登股** | 低价破净+传统行业+基本面差甚至亏损+老牌国企，老年散户（老登/爷叔）长期深套。典型上海建工（营收−28%、扣非−69%、PB1.1、2.4→3.88元，爷叔套10年） | 退潮/冰点末端的边缘情绪出口，弱市里还能讲故事的火种，击鼓传花一波流 |
| **爷叔股** | =老登股，源自"建工爷叔"套10年解套梗 | 同上 |
| **好人好股** | 国家队/机构权重白马中军（茅台一类） | 高位震荡期，指数共振用 |
| **游资抱团票** | 游资主导的题材抱团（≠机构白马） | 主升期 |
| **华字辈/阳字辈** | 名字梗玄学（生肖/谐音），跟基本面无关但市场会炒 | 情绪周期特定节点，跟随不纠正、不以无逻辑排除 |
| **庄票** | 主力控盘、纯图形、庄家拉连板出货（摘帽票常见） | 无板块效应秒拉板，别接 |
| **图形票** | 纯技术形态驱动、无主流情绪 | 北京炒家可打、光神"型必须符合神"否 |
| **中军/抱团趋势** | 机构核心资产，不是情绪龙 | 情绪主跌它不跌=风格切换，不是龙头穿越 |

## 六、仓位与纪律（动作用词）

| 词 | 口径 |
|---|---|
| **梭哈** | 单票满仓。学习期禁止，退学可不学 |
| **分仓** | 分散持仓控回撤（涅槃1-2成/票，1/3算重仓；科比十万就分仓） |
| **碎仓** | 极度分散 |
| **试仓** | 小仓位试水温（光神：舌头碰热水，感受冷暖防钝化） |
| **重仓** | 1/3以上，须核心+主升+计划内 |
| **满仓** | 仅三点共振：指数单边+板块当日核心+个股人气容量核心（光神满仓三条件） |
| **悟道** | 山还是山水还是水，返璞归真 |
| **复盘/错题本** | 涅槃：走马观花等于没复盘；光神：坚持做错题集、不研究新打法 |

## 七、心法金句（可操作版，背下来比背代码有用）

1. **先认市场，再认个股。** 没主线/风格/赚钱效应，不开新仓。
2. **只做龙头或低位，躲开中位和杂毛。** 中位股风险大（大面之源）。
3. **市场没有错，错的是预判。** 尊重市场，退潮就撤。
4. **盈亏比优先于胜率。** 强于预期加一档，弱于预期减仓。大肉来自少数核心单。
5. **买入分歧，卖出一致。** 一致加速人人觉得稳=卖出区。
6. **错了快切，不讲故事。** 超短不达预期隔日走人，跌停也切。
7. **计划外不出手。** 杜绝临时起意。
8. **弱水三千只取一瓢，能赚一块只赚七毛。** 留三毛济世。
9. **看好买入，不看好卖出。** 心中无顶底、手中无持仓、永不止盈永不止损。
10. **判断为末，应变为本。** 预判是为预案服务的，核心是右侧应变。
11. **涨多了跌，跌多了涨。** 亘古不变（光神第31条）。
12. **跟情绪走，千万不要自以为是。**（涅槃总纲）
13. **龙头首阴反包=行情继续；首阴被按=准备调整。**（陈小群总龙开关）
14. **该弱不弱视为强，该强不强视为弱。**
15. **下跌量小，资金锁仓看好。**（陈小群第31条）
16. **情绪周期是大道无形的基础。**（92科比）

## 八、最容易用错的词（我犯过的错，备忘）

| 词 | 错误理解 | 正确理解 |
|---|---|---|
| 低吸 | 抄底/跌多了接 | 预判当日涨停的强势票，高开几点买也算低 |
| 老登股 | 高股息防守白马 | 低价破净传统、基本面差、老年散户深套的边缘情绪票 |
| 防守 | 基本面好的票 | 便宜、跌无可跌、有故事可讲≠基本面防守 |
| 龙头 | 数板最多 | 能带板块、带跟风赚钱效应，换手包容（缩量一字只是情绪股） |
| 右侧 | 等二板三板接力 | 首板当天盘中确认（放量封板+板块效应）就是右侧点位 |
