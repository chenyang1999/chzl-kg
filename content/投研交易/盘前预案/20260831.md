## 仓位为什么是53%

R1给的建议是58%，主线扩散型，合理。但R6有一条strong_suggest明确说"情绪52.5分+47.6%炸板率=分歧剧烈期，建议仓位上限从58%下调至45%"。

我没有完全采纳45%（太保守了，82家涨停摆在那里），也没全信58%（47.6%炸板率不是闹着玩的），取了个中间值53%。

推导链是这样的：

```
R1主线扩散型 → raw_cap = 0.58
R7北向连续5日净流入 → +0.03 → r7_adj = 0.61
情绪周期：乐观分歧期（58分，20-60区间）→ 不override → 0.58
双主线 → multiplier = 1.0
R6分歧风险调整 → -0.05
最终 = min(0.58, 0.61, 0.58) × 1.0 - 0.05 = 0.53
```

53%的仓位，执行池3只票加起来最大仓位才25%，剩28%是留给加仓和T+1的。分歧期手里留着子弹不丢人。

## R6反证：11条strong_suggest全采纳

今天R6的工作量很大，一共出了16条反证：0条hard_reject + 11条strong_suggest + 5条soft_suggest。

为什么没有hard_reject？因为模式六（霸榜出货硬约束）的第二条——"主力5日净流出"——R5筹码数据降级了，确认不了。按规则，缺一条就不能算hard_reject，只能降级成strong_suggest。

**但这11条strong_suggest，D1一条都没打回，全吃了。**

吃的逻辑是：
- 农业线的60%亏损股 + 小市值庄股风险 → 全部剔除执行池，只留万向德农观察

- 分歧期仓位下调 → 从58%降到53%

这就是反证Agent的价值——它不是来否决一切的，它是逼着你在情绪热的时候冷下来，把那些"看起来很美但底子很脏"的票挑出来。
