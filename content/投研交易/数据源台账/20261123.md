| 符号 | 含义 |
|---|---|
| ✅ | 正常 |
| 🟡 | 部分可用 / 质量降级 / 未核实时点，不计真失败 |
| 🔴 | 真失败 / 缺失 / 无效 JSON |
| ⏳ | 未到产出时间 / 正在运行 |
| ⏸️ | 已知停用 / 有依据的合法跳过，不计正常成功率 |
