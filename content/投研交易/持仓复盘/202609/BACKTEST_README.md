## 六、口径说明（可审计）

- **A 严格照写**：预案买区/触发价一字不改，够不到即"未开仓" → 35 笔离场，胜率 28.6%
- **B 人读实操**：买区失真（相对生效日前收 <0.90 或 >1.30）时按通道语义执行（低吸/半路=开盘承接，打板=涨停价） → 补 7 笔，胜率 42.9%
- **C 并集**：A∪B 去重 = 42 笔成交 / 40 笔离场 = 27.5%
- 离场：日K最高≥止盈即止（分批按档位加权）；日K最低≤止损即硬性离场；成交当日也算（低开冲高同样能打掉）
- 预案未写止损时按 −7% 兜底，但**兜底止损不在成交当日触发**（不能用自编止损把当日打掉）
- 全部 40 笔逐笔明细见 `data/review/backtest_202609.json` 的 `rows[]`
