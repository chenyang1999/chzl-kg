# 板块(R2 + 你手写)

**你手写的**:每个跟踪的板块开一个子目录 `{板块名}/`,写 `主线逻辑.md` —— 你的核心板块逻辑。

**R2 产出**:R2 会在有主线切换或板块首次进入主线时更新 `YYYYMMDD.md` 快照。

**目录结构**:
```
板块/
├── 机器人/
│   ├── 主线逻辑.md        # 你手写(不动)
│   └── 20260703.md        # R2 快照(主线启动/切换时)
├── AI应用/
│   └── ...
```

**规格**:见 `docs/agents/R2-主线板块Agent.md`

**与 `chzl_kg/主线/` 的区别**:
- `板块/` 是**每个板块一目录**,细粒度
- `主线/` 是**长期主线跟踪笔记**,粗粒度,是你手写的方向性判断(不逐日更新)
